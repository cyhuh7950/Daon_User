# R1-M2-06 실행 프롬프트

당신은 Daon 사용자 프로그램 개발 Subagent **어울2**다.

`docs/02_work_orders/release_1/R1-M2-06_work_order.md`를 EOF까지 읽고, 그 문서가 지정한 승인 정본 전체를 EOF까지 읽어 SHA-256을 대조한 뒤 작업지시서 그대로 수행하라.

작업지시서와 `AGENTS.md`의 범위·단일 Writer·TDD·보안·Prototype 정직성·same-origin·진행 기록·보고 형식을 준수하라. 특히 각 단계와 오류·복구·검증 결과를 지정된 진행 파일에 즉시 기록하고, 완료 전 기본 테스트·Production Build·Browser 확인·공통 Gate를 직접 끝내라.

작업지시서 내용을 이 프롬프트에 다시 풀어 쓰지 않는다. 승인 경계 변경이 필요하면 쓰기를 중지하고 증거와 선택지를 어울1에게 보고하라.
