# R1-M2-02-C01 재작업 실행 프롬프트

`docs/02_work_orders/release_1/R1-M2-02-C01_correction_work_order.md`, 원 `R1-M2-02_work_order.md`, 실행 프롬프트와 승인 정본을 모두 EOF까지 읽고 현재 미커밋 Attempt 1 상태에서 재작업을 수행하라.

같은 어울2가 단독 코드 작성자로 계속한다. 기존 정상 구현과 다른 작업자의 변경을 되돌리지 말고, 수정 작업지시서가 지정한 결함·Test·Evidence만 최소 수정한다. 진행 기록을 각 C 단계와 오류·복구 직후 갱신하고, 실제 Chrome 네 폭과 전체 회귀까지 완료한 뒤 Attempt 2 정식 결과보고를 제출하라.

C7 `HANDOFF_READY` 뒤에는 구현 파일 쓰기를 중지하고 어울1의 검토·Commit·Push·불변 SHA를 기다린다.
